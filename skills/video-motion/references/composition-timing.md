# 布局与时间

用于分屏、画中画、动态强调或转场设计。先决定此刻让观众看什么，再选择效果。

| 表达需要 | 设计判断 | 实际合成检查 |
| --- | --- | --- |
| 操作与结果同时可见 | 主辅视窗及切换时机；真实时间关联 | 小窗仍看得清关键动作，不挡主画面/字幕；不同时间不伪装同步 |
| 同场景动作并置 | 相同/互补动作、各窗先后和主次 | 不让每窗同时抢焦；裁切仍保留动作与主体身份 |
| 语义强调 | 缩放跳变或连续推近，起点/落点对应重音 | 分辨率与安全区，重点可读停留；每个切口不机械 zoom |
| 避开其他产品 | 裁切、主次调整或替代源段 | 不损坏关键动作/接触，不把他物演示说成目标产品 |
| 解释细节 | 标记/局部放大与原图关系 | ROI、遮罩、放大窗口、文字共同对齐，跟踪/边缘不漂 |
| 从一个状态进入另一个 | 方向/形状/遮挡/内容关系 | 两侧源段和余量可接，过渡期间主体可追踪；SFX 不补救错位 |

动态需要进入、可读停留和退出。参数指定了缩放值不证明存在动画，渲染某个单帧也不证明过程成立。检查文字、圆角、装饰、原片裁切和透明度是否一起正确变化。

初剪布局先说明位置、内容、时间与主次；认可的同一实例继续完善，不重造模板。关键转场和声画配合在现有标记/决定中保留意图、源、落点与核查状态；声音有作用才加入。

将渲染结果回填当前采用后再看所有图层：字幕安全区、包装遮挡、底层露出、边缘/Alpha、色彩解释、时钟和前后剪口。单个组件预览通过不能替代实际合成。

参考：[Yale Editing](https://filmanalysis.yale.edu/editing/)、[Yale Cinematography](https://filmanalysis.yale.edu/cinematography/)。这些是按表达选择的应用，不把技法数量作为质量指标。
