# 结构与信息安排

用于需要构思或重组的任务。先写观众此时知道什么、还想知道什么，再决定镜头顺序；已有被采用粗剪按用户修改范围继续。

| 表达需要 | 可比较的结构 | 必要条件与核对 |
| --- | --- | --- |
| 先让人看到价值 | 结果先行，再回过程 | 真实结果和过程可对应，后文兑现开头；避免亮点耗尽后重复揭示 |
| 让功能被理解 | 问题/原因 → 操作 → 结果 | 不能省掉关键触发再假装证明功能；装饰音效不补造事实 |
| 延迟揭示 | 细节 → 整体；先闻后见 | 后续确实回答前面问题，不能长期藏主体造成困惑 |
| 比较或同时推进 | 并置、交叉、同场景多画面 | 明确是否声称同一时间/条件，各线返回时增加信息 |
| 压缩重复过程 | 省略熟知步骤，保留状态变化 | 观众能补全省略；不拼造一次成功或公平比较 |
| 情绪/主题呼应 | 建立某画面/声音，变化后再现 | 先有可辨识建立，再现增加含义；无意义重复不算回收 |

摄影顺序只是候选组织。每段需要原因/动作/反应、空间建立或声音提示时，先查素材是否真实支持；缺口可通过已有素材重组或有依据的补充解决。

声音从结构设计时参与：它可以先建立场景、跨画面维持关系、预告下一信息或给反应留空间。不要先把画面压到无法停留，再希望 BGM 修好节奏。

只为有争议的结构比较足够不同的方案，明确各自信息揭示和素材条件；不把固定镜头数或时长当叙事规律。

参考：[Yale Editing](https://filmanalysis.yale.edu/editing/)、[Yale Sound](https://filmanalysis.yale.edu/sound/)、[Randy Thom: Designing a Movie for Sound](https://www.asoundeffect.com/designing-a-movie-for-sound/)。上述选择/核对是制作应用。
