# 创意与分镜

写入或下载文件前，先落实[保存位置与临时文件](references/storage.md)：复用已有配置；缺少时只向用户确认存放习惯及素材、项目的位置。输出与缓存落点明确后再执行，独立任务不强制建整片项目。

从原稿、目标观众、参考与已有素材确定这次内容筹备。可独立做结构或镜头设计；沿用现有表达记录，分别保留文稿、参考、实拍候选与最终采用。

- 明确主线、每段让观众知道/看到什么、依据和观看窗口。已有稳定 ID 与被采用结构继续使用，改口结合实际录音核对原意。
- 需要组织或重构时读[结构与信息安排](references/story-structure.md)，比较有实质区别的揭示顺序、动作/反应、视点与声音走向。拍摄/文件顺序不自动等于叙事顺序；用户已剪好的结构是修改基准。
- 参考检索使用实际可用平台/素材，注明来源与用途；示意图和生成参考不能冒充真实拍摄效果。工具未用成功不宣称已搜索。
- 拍摄后先匹配已有候选关系，录次表现与精确气口留到连续看听后确定。估算文字时长不成为真实 VO 时钟。
- 对需要包装的位置明确内容、主次、区域和观看窗口，优先复用本片采用模板；对白采用后再落实精确时间。
- 区分待定位、待核实、待制作和有依据的待补拍。新增输入只更新相关部分，不整版重建。

按任务交付表达/结构、镜头职责、参考/候选及具体缺口；只做参考准备时不声称已选定实拍录次。沿用项目现有格式，短任务可直接给可执行说明，无需另建分镜产品或必填表。

确定性操作使用已有 CLI/API/MCP；原生修改保留当前工程单写入者。当前项目采用本套 Workflow/Board 时才读[工具接入](references/workflow-adapter.md)。
