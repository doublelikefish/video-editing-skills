# 选镜、剪点与覆盖

只读本次问题对应部分。技法是解决表达/感知问题的候选，采用还要靠实际两侧声画比较。

## 选镜从职责出发

先确定此刻需要动作、结果、解释、情绪、对照、节奏还是遮切口。查看相关已有候选，包括未进计划的源；比较动作身份/阶段、构图、焦点、运动、源声音与余量。

- 同一表达的替代录次比较真实表现、完整字头尾、语气和动作；不把互补句当 A/B。
- 同产品画面未必证明本功能；拿其他产品的镜头不能冒充目标演示。必要裁切应同时保护动作和产品身份。
- 入出点应落在可用子段；不要因整条有晃动而漏掉稳定窗口，也不要因某帧漂亮而采用不稳的连续段。

## 动作、注意力与运动

| 问题/目的 | 可比较的方法 | 实际核对 |
| --- | --- | --- |
| 一个动作跨镜连续 | 动作匹配、动作中或前后切 | 同一动作身份/相位、手物状态、速度，不能重复/漏做 |
| 延续动势 | 相容方向/速度趋势、注意位置 | 屏幕运动和相机路径分开；同标签不保证相接 |
| 落定或触发 | 动接静、静接动 | 保留结果/反应可读停留，启动有动机 |
| 突出语义/细节 | 景别切换、punch-in 或连续推近 | 选择语义重音、分辨率余量、起落与主次；并非每切都 zoom |
| 让眼睛找到下一信息 | 视线、构图/图形匹配、空间重建 | 焦点/主体位置、方向与空间是否被误读 |
| 重组画面关系 | cutaway、分屏、画中画 | 每个视窗有职责；不同时间不伪装同步，其他产品不过度抢焦 |

相机、主体、光学和后期运动分别识别。摇/移/跟随可以选起点、过程或落点，但应保留其揭示作用。拉焦核对两个对象和完整焦点交接，不只检查两张静帧。稳定化/裁切后再看画面边缘、主体形变及关键动作。

## 节奏不等于持续短切

同时看镜内变化、镜头交接、句群/段落与全片推进。让语义、动作、反应和音乐轮流决定切点；需要时间被理解的画面应停留。

短切组应积累信息或能量，并有落点/张弛；连续相同密度会麻木。动作/画面可与音乐重音对齐或有意错开，但不要为卡拍截断字尾。保留不切也是选择。

如果用户要求整体或分段提速，按明确范围共同映射原剪辑、VO、停顿、字幕、包装和相关声音；提速不授权重排原内容。核对变速后顺序、长度、同步及原句完整性。

## B-roll 进出覆盖

1. 找到当前被遮的 A-roll/VO 条目、精确剪口与同组上层，先确认反馈针对的是哪个切口。
2. 在源内选能承担职责的窗口，留可用进入/退出余量；时间线覆盖同时绑定本句与下一句应露出位置。
3. 检查进入前 → 剪口两侧 → 退出后，包含下层及其他覆盖层。只盖住切点中心不能证明无回闪。
4. 若露出旧口播或挡住下句，先试覆盖位置/长度；当前镜头有效时不盲目换源。撤错镜仍需补原职责。
5. 连续看听包含前后句群的实际合成；定格和计划 JSON 不能确认观看感受。

## 转场与声音关系

硬切用于清晰交接；叠化/淡入淡出表达交叠或段落边界，需要可用余量和可读重叠。甩镜/遮挡依赖两端方向、速度与遮挡区域，随机模糊加 whoosh 不会自动成立。

J-cut/L-cut 允许声画分开切，使场景预告、对白反应或关系延续；实际检查嘴型、字头尾及声源归因。切点不能只按字幕字尾或模型近似时间决定。

将关键采用理由放在既有备注/标记中：目的、源窗口、目标剪口/动作、方法、实际效果及缺项即可，不增加每镜必填表。

参考：[Yale Editing](https://filmanalysis.yale.edu/editing/)、[Yale Cinematography](https://filmanalysis.yale.edu/cinematography/)、[Yale Sound](https://filmanalysis.yale.edu/sound/)、[Walter Murch](https://transom.org/2005/walter-murch/)。具体窗口/覆盖检查为制作应用，不是教材原句或自动质量评分。
