# 初剪与精剪

写入或下载文件前，先落实[保存位置与临时文件](references/storage.md)：复用已有配置；缺少时只向用户确认存放习惯及素材、项目的位置。输出与缓存落点明确后再执行，独立任务不强制建整片项目。

交付有依据的选条、可编辑修改与实际看听结果。按请求从用户粗剪继续，或从素材开始；工作深度随问题展开。

## 先固定本轮要交出的初剪

从最新原话和已采用内容，在现有接续/反馈中简短列出本轮必须呈现什么、保留什么、哪些精修已明确留后；制作方案中的自行延期不算用户同意。用户要求配合现有模板、双机素材或已有声音时，这些是本轮实际组接的内容，不能先交单机口播再说下轮补齐。无需新增清单系统，也不要求用户重新解释已有约定。

多机位、Log 或模板合成涉及新执行路径时，先做包含相关因素的短段，核对源窗口、同步、基础还原、内容槽及前后切口，再展开整片。为节省渲染时间可以降代理尺寸或复用已验证缓存；不能去掉必要处理、沿用过期缓存或删减已要求的内容。尚做不到的部分保留待完成，继续处理已授权且能推进的工作。

## 保护真实输入

- 已有用户粗剪/DRT：镜头、VO 顺序、剪点、停顿、变速及人工声音/调色都是基准。先读当前现场，必要导入由原生写入者通过受支持接口完成；不得从原素材或不完整端点重建“等价”剪辑。
- 从素材/文稿开始：复用表达、筛选、候选、排除和模板。同一表达的正式录次需要实际比较，互补句不是替代录次。
- 对白驱动影片尽早使用与当前采用同步的辅助字幕/对白 cue 理解句群；最终字幕样式可后做，文字不替代听审。

## 使用 Resolve 创建或接续

- 先检查当前会话实际可调用的 MCP；仓库已安装不等于已挂载。MCP 不可用时，继续使用已有 Python SDK/CLI。常规创建工程、导入、保存不需要浏览器或文件名对话框。
- Resolve 未运行且本轮已授权原生制作时，通过系统入口启动一次；已有进程不重开、不强退。启动后有界等待 SDK 和项目管理器就绪（通常 30 秒，慢启动可延至 120 秒），不能凭第一次连接返回空就要求用户改设置或改交 XML/MP4。
- 区分无当前工程、未保存的空白启动工程、真实已有工程。确认为空的启动 `Untitled Project` 不先调用保存/导出以触发命名弹窗：核对准确 ID、未列为已保存、零时间线、空媒体池/子目录且未渲染后，才创建命名工程并保存、读回。未知或有内容仍按已有工程保护；不替换其他写入者的活动工程。
- 使用本套 Workflow/Pipeline 时，按[工具接入](references/workflow-adapter.md)调用现成的等待/创建入口。超时后先区分 SDK 环境、启动阻塞与真实脚本配置问题，只将确需用户操作的阻塞交回用户。

## 从表达选到剪点

1. 明确本段意义、注意力、动作和声音如何接续。结构、运动或节奏有问题时，读[选镜、剪点与覆盖](references/cut-decisions.md)的相关部分。
2. 查现有素材索引、表达对应、观察与缓存，包含相关未用/未进计划候选。计划范围不证明全库覆盖；缺观察不是无素材。比较实际源窗口，采样不足就补局部连续观察。
3. 决定组接和两侧入出点，记录为何此时切。直切、运动匹配、停留、裁切/缩放、分屏、画中画和声音先入/延续按表达选择；技法名不能代替采用理由。
4. 用已支持的 CLI/API/MCP 落实具体修改，保护当前完整基线、关联声画与人工处理。整体/分段提速使用共同时间映射；音轨、ripple 或复杂变速不支持时不以全量重建掩盖。
5. 连续看听改后段落、相关图层与前后句群/动作。先核对真实对象与版本，技术读回和视听结论分别记录；未听不能选“最佳”，冲突先回源。

## B-roll 覆盖必须有对象和退出点

承担遮切口职责时，绑定目标 A-roll/VO 条目及当前剪口，确定源窗口、进入/退出位置和下一句应露出的画面。检查覆盖区间、同组所有图层和退出后的下层，避免旧口播回闪或下句被遮。切口问题先比较位置/长度/余量，再判断换镜；已认可镜头不无依据撤掉。

用户举例说明普遍问题时，恢复完整有效要求、适用段落及相关候选；局部意见不默认全库重筛。具体拒绝只作用于其真实范围；撤错镜后检查原职责是否补上。

## 返回同一作品

- 初剪整段的完成范围包含必要输入还原/机位平衡、声音可理解性和可见包装布局；单点修改按本轮影响处理。已有调色、声音、字幕和模板实例继续复用。要求原生可编辑时读回真实源素材条目、范围和轨道；把整片 MP4 放进一条时间线只得到播放预览。
- 改源、剪点、位置或速度后核对声音、字幕、包装、色彩与反馈映射。连续退回先用失败处真实上下文验证修法，再扩展请求范围。
- 复用工具回执，补采用理由、实际检查、未完成项和正确结果版本；有原反馈就回到原意见。导出成功、删除“待核”字样或线程结束不关闭质量要求。
- 输出前检查项目是否已有 Review 版本、反馈批次、Review 根或历史回执。已有链时沿同一 Review 登记当前预览、绑定父版本并回写原意见；只有新项目或用户明确切换时，才用聊天/文档直接交付。局部试做不自动结束整片任务。
- 最终回复前重新对照本轮必须项与最终实际预览、原生读回、看听覆盖及反馈入口，逐项指出实际落点或剩余项。未采用指定内容、未做必要处理、未完成看听或载体未交付时，只能称工作预览/部分完成；“初剪已搭好/完成”也受此约束，不能在标题报完成、末尾再列基础制作未做。

项目采用 Workflow/Pipeline 时才读[工具接入](references/workflow-adapter.md)，按其已有计划、检查和回调格式执行。其格式检查不替代上述制作判断。
