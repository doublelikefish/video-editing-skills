# 视频剪辑 Skills

**把你想做的视频、已有素材和修改意见，交给一个有完整制作流程的 AI 助手。**

拍完素材之后，往往还有一长串工作：挑镜头、整理口播、搭结构、处理切口、选音乐、做字幕、调色、加包装，再一轮轮修改。这个 Skill 包把这些环节整理成 AI 助手可以按需使用的方法，让它知道下一步该做什么、该向你确认什么，以及交给你之前要检查什么。

它来自实际视频项目中反复修改的经验，尤其关注几件容易影响交片的事：镜头找到了却没用、B-roll 遮错了切口、改声音时丢了原来的调色、反馈提了很多条却只改了一部分。

## 适合怎样的视频

产品评测、数码开箱、口播分享、采访、旅行记录、Vlog，以及其他需要整理素材、剪辑和反复修改的视频。

你可以从一个想法开始，也可以已经有文稿、拍摄素材，甚至已经自己剪好了第一版。已有粗剪时，助手会以你指定的版本为基准接着做，保留你要求留下的结构、声音、调色和人工修改。

## 你可以这样用

**从拍好的素材开始：**

> 我拍了一条手机壳体验视频，素材在……，项目放……。我用剪映，先帮我搭一版初剪。开头想有一点节奏感，后面以讲清楚使用体验为主。

**继续自己的粗剪：**

> 这份是我已经剪好的版本。保留段落顺序和口播，只帮我处理切口、补合适的 B-roll，再把声音和画面整理一下。

**按反馈修改：**

> 第六秒音乐断得太突然，后面的 BGM 也偏小。请看前后这整段，重新处理衔接，保留现有调色。改完把这几项分别核对，再给我看。

**只做一个环节也可以：**

> 帮我从这批素材里找出产品吸附、旋转和展开的镜头，给出能用的时间段，先不要动时间线。

不用一次把所有信息填完。助手会先读取你已经提供的内容，再补问影响这轮工作的缺项。

## 它会怎样配合你

**先把这条片的基本条件说清楚。** 要做什么、使用什么软件、素材在哪里、项目存哪里、以哪一版为准。你有自己的习惯就沿用；没有的话，它会给出简单的存放建议，并在项目里保存接续记录。

**再按内容决定怎么剪。** 素材筛选要找到具体可用的片段；初剪要考虑口播、动作、镜头职责和前后关系。分屏、画中画、缩放、声音先入或延续等手法，围绕表达来选，不要求每条片都用同一套效果。

**把声音、画面和字幕一起照顾到。** 音乐衔接需要考虑乐句、节奏与音色，调色需要保留正确的输入解释，字幕跟随实际采用的台词。改动剪点、速度或素材后，也要检查这些内容有没有一起对上。

**你的反馈要一条条落到结果上。** 助手需要记录改了什么、落在哪一版和哪个位置、实际检查了哪些范围，以及还有什么没做。技术检查、真实看听和你的接受分别记录；还没完成的内部检查，不能直接交给你代查。

**接着做时能找回进度。** 项目配置、当前版本、有效反馈和下一步有明确保存位置。换一个对话继续时，先读取这些记录，不靠文件名猜“最新版”。

## 包里包含什么

完整包有 **10 个 Skill**。安装后由助手按任务读取，不需要你挨个操作。

| 环节 | 能帮你推进的工作 |
| --- | --- |
| 项目配置与接续 | 目标、存放位置、工具检查、基准和项目记录 |
| 创意、文稿与分镜 | 主线、结构、参考、画面职责和拍摄缺口 |
| 素材接收与筛选 | 找镜头、比较候选、定位动作和可用时间段 |
| 初剪与精剪 | 口播、选镜、剪点、节奏和 B-roll 覆盖 |
| 调色 | 输入还原、曝光白平衡、机位匹配和风格 |
| 包装 | 标题、标注、分屏、画中画和现有模板复用 |
| 声音 | VO、同期声、BGM、SFX、衔接和混音 |
| 字幕 | 实际台词、时间同步、样式和显示检查 |
| 审片与修改 | 收集意见、逐条修改、核查和回传 |
| 输出与交付 | 导出规格、成片检查、工程依赖和归档 |

这些环节可以交叉，也可以跳过已有成果。只修一句字幕，不需要重新分析整条片；初剪需要的基本声音、色彩和包装，也不应该全留到最后再补。

## 安装

将这个仓库链接交给支持 Skills 的 AI 助手，可以这样说：

> 请把 https://github.com/doublelikefish/video-editing-skills 里的全部 10 个 Skill 安装到你支持的 Skill 目录，保留我已有的配置；若遇到同名内容冲突，先告诉我。安装后，从 video-production 开始帮助我制作视频。

也可以下载仓库，把 `skills/` 里的十个完整文件夹复制到你的助手支持的位置。具体目录和可选安装命令见 [安装说明](INSTALL.md)。

宿主发现安装内容后，就可以正常描述剪辑任务。首次接入完整项目时，助手会创建或补充项目规范和接续文件；已有项目沿原记录继续。安装本身不会扫描或改造你的所有项目。

## 软件与工具

这套方法不绑定某一款剪辑软件。你可以使用剪映、DaVinci Resolve、Premiere、Final Cut，或其他适合自己的工具；系统、软件版本和助手能调用的能力需要分别确认。

包里提供的是制作方法、项目模板和检查规则，另附一个可选安装器。**不包含剪辑软件、我们的制作脚本、模型、素材或 API 账号。** 助手会优先使用你已有的工具；需要额外能力时，再检查是否能接入、补装或编写本项目所需的小脚本。

你不必自己写脚本，但助手能自动做到哪一步，取决于它是否能访问你的文件、控制相应软件，以及看听实际媒体。做不到的部分应明确说明，不能把操作建议说成已经完成的成片。

反馈也不绑定专门的 Review 工具：没有评审服务时，直接在聊天里说就可以；已经在用评审工具的项目，则沿原来的版本和意见继续。

## 关于效果

这是一套可复用的工作方法，不承诺固定时间出片，也不把“导出成功”当成剪辑质量通过。文件安装和部分本地处理流程已做隔离验证；所有题材、编辑器和客户端的自动执行并没有全部验证。

真正的选镜、节奏、情绪和声音效果，仍需要在你的素材和完整上下文里判断。欢迎在 Issues 中反馈实际遇到的问题：做什么片、使用什么工具、期待什么结果、助手实际做了什么。请不要公开私人素材、账号凭证或不便分享的项目内容。
